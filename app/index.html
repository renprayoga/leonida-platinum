    The road to the platinum, in five stages built from the official descriptions: story first, then stranger strands, then the collectible sweep, then activities, then money and combat clean-up. Each stage lists its trophies in the order to earn them.

    Six trophies can be missed — each is tied to a one-off moment or a one-way choice in the official description. Do these while the moment is available; everything else can be cleaned up after the story.

    Spoiler setting

    When spoiler hiding is on, story trophies you have not earned yet show as “Hidden story trophy” — no name, no description — until you earn them. Collectibles, activities and the rest stay visible.

    Save, export, import

    Your checklist is saved in this browser (localStorage) automatically. Export downloads a JSON file with your earned trophies; import reads one back. Import keeps only names from the official list and ignores anything else.

    Sources & honesty note

    Official names, descriptions and grades are as PlayStation publishes them, via the Exophase trophy list; PSN progress counts (such as 42 Shooting Range challenges) are from PSNProfiles. Every guide is written in our own words from the official description. Where the description does not pin down an exact location or step, the guide says so instead of inventing one — a cited guide beats an uncited one, however detailed.
